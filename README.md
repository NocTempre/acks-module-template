# acks-module-template

**Retired 2026-11-18. This repository is a read-only archive.**

It held the shared toolchain of the NocTempre ACKS II Foundry VTT modules and
copied it into each module repo. Those modules merged into one,
[`foundryvtt-acks-extras`](https://github.com/NocTempre/foundryvtt-acks-extras),
and the toolchain was folded into that repo at its commit `22cc1101`. It is
edited there now: the tools, their tests, the release workflow, the Claude Code
skills, rules and hooks, and `docs/TOOLCHAIN.md`.

Nothing here is synced anywhere, and nothing here should be changed.

`docs/DECISIONS.md` stays as the record of why the toolchain is the way it is:
the index in `foundryvtt-acks-extras`'s `docs/DECISIONS.md` links to its
entries, as this repository's last commit before this notice (`a85dd50`) holds
them. New rulings are written there.
